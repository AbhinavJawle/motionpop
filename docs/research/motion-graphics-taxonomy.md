# The Complete Motion Graphics Taxonomy

A reference list of motion graphics types, for planning the style and component library.

**Fit** = how well each type suits template-driven AI generation (Fable-quality templates + cheap model filling parameters):
- **H** = high (structured input, very templateable)
- **M** = medium
- **L** = low (needs heavy custom work every time)

## What this means for the product

**Most templateable, ideal for the MVP library (structured input → consistent premium output):**
1. Data visualisation: bar, line, counter, comparison, ranking, timeline
2. Maps: globe zoom, route, choropleth, pins
3. Kinetic typography: headline, captions, lower thirds, callouts, quotes, lists
4. Explainer basics: process steps, infographic, money explainer
5. Branding: logo sting, intro/outro, end card
6. UI/product: device mockup, feature highlight, code animation
7. Transitions: the full H-rated set

**Hardest to generate well (save for later or avoid):**
- Character animation in 3D sets, lip-sync, cutaways, anatomy, camera fly-throughs, analogy visuals. These need heavy human direction, as your own test video showed.

**Rule of thumb:** the more structured the input (numbers, places, dates, text, logos), the better AI + templates perform. The more the output depends on story, acting and camera choices, the more it needs a human director.
