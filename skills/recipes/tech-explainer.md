## Intent
Tools, code and products, shown on every word.
Each named tool, step and option gets its own picture on the word that names it.

## Pacing
Scenes run 1.2–3.2 seconds.

## Layout mix
- split: 45%
- speaker: 25%
- full: 20%
- card: 10%

## Preferred templates
logo, logos, terminal, flow, compare, list, website, checklist

## Hook
Open on the tool or the result: a logo, a site or a bold claim the reel then proves.
Default hook style: visual.

## Visual grammar
Every named tool appears as its logo on the word. Steps become flows, commands become terminals, options become stacks. Lists grow across cuts.

## Music
Confident minimal tech house, soft synth plucks, tight hats, warm sub bass, 118 bpm.
Mood when set to auto: minimal-tech.

## Sound effects
Density: medium.

## Banned
- generic circuit-board backgrounds
- robot imagery
- matrix rain
- stock "hacker in a hoodie"
