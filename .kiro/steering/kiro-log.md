# Kiro log

After a meaningful step (spec phase approved, task group done, hook added, bug fixed, MCP/steering change), append an entry to `KIRO_LOG.md` at the repo root:

```
### YYYY-MM-DD: <short title>
- Kiro feature: <spec | steering | hook | MCP | PBT | bugfix spec | ...>
- What it did: <one or two sentences, concrete>
- Evidence: <file paths, test names, screenshot path>
```

Only record facts that exist in the repo. No time estimates or claims that can't be checked.
