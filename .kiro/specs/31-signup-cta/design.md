## Geometry
Artboards are 800 x 760; the button's top edge is y = 640; artboard = ghost px + (-112, +40). One artboard unit is 5.4224e-4 of the button width (the ghost is 0.353 of it, centred at 0.646). CSS: canvas box 43.379cqi x 41.21cqi at left 42.883cqi, top -34.703cqi; stage headroom 33cqi.

Stacking inside the link (isolated): glow, body canvas, face (z 1), label + arrow (z 2), hands canvas (z 3).

## State machine "Pip" (both artboards)
| Layer | States | Keys |
|---|---|---|
| Idle | Idle (360 frames, loop) | Float node y/rotation/scale, eye scaleY (blink), hand nodes |
| Hover | Rest ⇄ Perked, 300 ms in / 420 ms out, early exit | Perk node, Eyes node / Grip nodes |
| Press | Still, AnyState → Bounce (48 frames, reset) → Still at 100 % | Bounce node |

View model `PipCta`: `hover` (boolean), `press` (trigger). The host sets both instances.

Idle curves are sums of whole-loop sinusoids keyed every 45 frames as Hermite (`cubicValue`) segments, so frame 360 meets frame 0 in value and velocity.

## Runtime notes
- `useRiveFile` (react-canvas-lite 4.38.1) puts the file into state before it loads; under StrictMode a cleaned-up file reached `useRive` ("Problem loading file; may be corrupt!"). `useLoadedRiveFile` hands over a file only after `init()`, holds one reference, and releases it on unmount.
- `RiveComponent` ignores `style` when given a `className`; canvas visibility is CSS (`data-ready`).
- A Rive workspace on a plan with the splash watermark publishes a file that draws ~2.3 s of opaque black on load (measured in Chromium with canvas-lite 2.49.2 and in the page). Hence R4.3.
